# 🛒 Amazon Project – E-Commerce Front-End Clone

> A functional e-commerce storefront built with vanilla JavaScript, HTML, and CSS — inspired by the Amazon shopping experience.

This project is a front-end clone of Amazon's core shopping interface. It was built as part of a JavaScript learning journey to practice DOM manipulation, shopping cart logic, and responsive UI design. The site is deployed live on **GitHub Pages**.

🔗 **Live Demo:** [lenis03.github.io/javascripts-amazon-project/](https://lenis03.github.io/javascripts-amazon-project/amazon.html)

---

## ✨ Features

- **Product Catalog** – Browse a selection of products with images, names, and prices.
- **Shopping Cart** – Add items to the cart, view the total, and manage quantities.
- **Returns & Orders** – A dedicated section for tracking orders and returns.
- **Interactive UI** – Dynamic updates without page reloads, powered by vanilla JavaScript.
- **Responsive Design** – Adapts to different screen sizes for desktop and mobile viewing.

---

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure
- **CSS3** – Custom styling and layout
- **JavaScript (Vanilla)** – All interactivity, cart logic, and DOM manipulation

No frameworks or external libraries were used — keeping the code lightweight and focused on core front-end skills.

## 🚀 Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lenis03/javascripts-amazon-project.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd javascripts-amazon-project
   ```

3. **Open `index.html` in your browser** — no build tools or server required.
